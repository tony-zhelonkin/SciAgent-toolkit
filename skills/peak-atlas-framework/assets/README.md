# assets/

Bundled templates loaded by the FILTER / VALIDATE stages.

| Asset | Purpose |
|---|---|
| `peak_filtration_config.yaml` | Parameterized template for the metadata pre-filter, stratified sampling, adaptive Primary+Rescue sparsity filter, and all validation thresholds. |

The `rare_markers` panel is an EXAMPLE (mouse bone-marrow); replace it with your
own markers. Every threshold is tunable; see
`references/rare-celltype-protection.md` and `references/validation-battery.md`.
