How to read this ▾

Direct call is fine and necessary. It only becomes a problem when the callee is removable.

Shared state is OK at small scale. Becomes corrosive as the state structure grows: any shape change forces coordinated edits, and out-of-order writes produce silent bugs.

Background knowledge is always a smell — the compiler, the type checker, and the test suite cannot catch a violation. The architectural prize for pruning a removable component with background-knowledge edges is that those implicit invariants disappear entirely.
