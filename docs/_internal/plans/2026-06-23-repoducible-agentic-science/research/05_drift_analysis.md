| Location | Status | Content |

| Canonical `AGENTS.md` (toolkit self-docs) | ABSENT | N/A — self-referential toolkit doc, not project guidance |

| DC `AGENTS.md` | PRESENT (bespoke) | `save_figure()` + `POINT_SIZE` + two-file convention — Python/scRNA-specific |

`docs/guidelines/visualization.md` exists in canonical but is not injected or referenced from any project template. **Not centralized. Not propagated.**

## 7. Key Findings Summary

### 7.1 What is NOT drifting (architecture is sound)

1. **Content of agents and commands is frozen by symlink.** No repo has edited a copy of `code-reviewer.md` or `commit.md`. The symlink-based delivery model is working — content drift is structurally impossible.
2. **DC and 14839 AGENTS.md scaffolded sections match the template.** The four critical rules, artifact captions, and docs-namespace table are verbatim.
3. **CLAUDE.md = @AGENTS.md everywhere.** This constraint is perfectly upheld.

### 7.2 What IS drifting or missing

1. **STING AGENTS.md was never built from the template.** It is a hand-crafted document that is missing the four critical rules, the artifact captions rule (C, B pain points), and the docs-namespace table. It gained two sections (figure discipline, compute/viz split) that are valuable but exist nowhere else.

2. **Figure legibility has three incompatible implementations.** STING has the claim-audit frame (one claim = one figure). DC has the Python `save_figure()` + `POINT_SIZE` frame. 14839 has the R `project_theme()` + `save_figure()` + `by_contrast/` frame (in a planning doc, not AGENTS.md). None of these cross-reference or align with each other or with `docs/guidelines/visualization.md`.

3. **The planning decomposition recipe (Opus/Sonnet cadence) has never been written down.** It is observable only in STING session artifacts as an emergent practice. No canonical file encodes it. It will recur as repeated steering in every new project.

4. **Source-table adjacency is ad-hoc or buried.** STING implements it as flat `fig3*_data.csv` files in `tables/`. 14839 has a rich formalization with `tables/_overview/<same-stem>.csv` sidecars and `save_overview()`, but this lives in a per-project planning doc, not a reusable skill or template.

5. **No explicit "no ephemeral scripts" rule exists anywhere.** The compute/viz naming discipline in STING's AGENTS.md comes closest, but is absent from canonical.

6. **STING and DC are 24 commits behind on TE-relevant skills.** For STING specifically (which is doing TE analysis), this means `te-gene-featurecounts`, `te-geneset-gsea`, and `annotate-bulk-rnaseq-data` are not available to the agent even though they exist in canonical.

7. **DC injects an archived skill.** `mllmcelltype-consensus-annotation` is in `skills/_archive/` in canonical but live-injected in DC via the `_injected` synthetic overlay. This is a production dependency on an archived artifact.
