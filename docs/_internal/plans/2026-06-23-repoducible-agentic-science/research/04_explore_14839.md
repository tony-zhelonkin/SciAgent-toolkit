## 02_analysis — Compute→Viz + Theme

Naming: compute `NN_<concern>.R`, viz higher-numbered `NN_<concern>_viz.R` reading checkpoints only, never inline ggsave. Anti-pattern named "AdaW ggsave-inside-compute". E.g. 03_de_model_fit.R → 11_de_viz.R; 22_te_enrichment.R → 25_te_enrich_viz.R; 30_xcontrast_join.R → 33_coupling_viz.R.

### figure_helpers.R (centralized styling entry point)

`project_theme(base_size=NULL, legend=TRUE)` — sources RNAseq-toolkit `custom_minimal_theme_with_grid()`, falls back to theme_minimal; overlays sizes from `CONFIG$figures` (text=base, title=18 bold, subtitle=13, axis_title=15, axis_text=13, legend=13, strip=14; minor grid blank; title.position="plot").

`save_figure(plot, stage_id, name, contrast=NULL, wide=FALSE, height, width)` — width from CONFIG$visualization (wide→width_wide 14 else width 10), height 8, dpi 300; dir = `overview_path()` or `contrast_path()`; uses cairo_pdf for .pdf.

`save_overview(plot, stage_id, name, table_df, finding, script, fn, config_kv, input, ...)` — **atomic triple**: writes `figures/_overview/<name>` + `tables/_overview/<stem>.csv` + README caption in ONE call.

`style_running_sum(p, ylim=NULL)` — pins legend inside panel (c(0.98,0.98)), clamps y from `CONFIG$figures$running_sum_ylim`, suppresses legend on panels 2..n. Fixes "long DB name squishes panel" + cross-figure comparability.

`contrast_subtitle()` / `direction_cue(contrast_name)` — laconic ≤8-word corner cues; detects C-family (difference-of-differences) via `grepl("\\)\\s*-\\s*\\(", expr)`.

`contrast_path()` / `overview_path()` — dir helpers that mkdir the by_contrast/<c>/ and _overview/ subdirs. `curated_focus()` — config-driven family focus, never hardcoded.

## Reusable Patterns to Promote

- **A `project_theme()`** — single styling entry, all sizes from `CONFIG$figures`, toolkit-theme base with fallback.
- **B `save_overview()`** — atomic figure + neighboring table + caption.
- **C `write_contrast_readme()`** — signed direction-legend generator from a `CONFIG$contrasts` entry.
- **D `write_caption()`** — idempotent per-artifact caption with Script|Function|Config|Input table.
- **E `append_master_table()`** — schema-checked, lowercase-`nes` enforced, database-column dedup, round_numeric_cols.
- **F `style_running_sum()`** — figure-series comparability (legend inside, y clamp from config).
- **G Plan INDEX template** (`00_INDEX.md`: scope, phase table, config_additions, global notes incl. idempotency + compute→viz + claim ladder).
- **H Per-phase file template** (`NN_<slug>.md`: header w/ figure-style contract, objective/scope/out-of-scope, inputs, outputs, implementation, captions, acceptance checks w/ grep asserts, gotchas).
- **I Research note naming** `YYYY-MM-DD_NN_<topic>.md` with synthesis note as plan input.
- **J `direction_cue()`/`contrast_subtitle()`** — laconic on-figure cue derived from a config contrast entry instead of paragraph annotations.

Acceptance-check idioms worth standardizing: grep finds NO `voomLmFit|eBayes|ggsave(width=<number>`; sources figure_helpers.R + applies `+ project_theme()`; per-contrast artifacts in by_contrast/<c>/, cross-contrast in _overview/; every by_contrast README states sign convention; `grep -c '_internal' README.md` == 0.
